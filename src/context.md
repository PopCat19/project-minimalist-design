# Context

- `base16-export.nix` — Exports PMD color schemes as Base16 YAML files
- `dev-server.ts` — Development server with auto-rebuild and live reload
- `dev-shell.nix` — Development environment shell for PMD project
- `oklch2rgb.nix` — Converts OKLCH color values to hexadecimal RGB
- `pmd-core.nix` — Core library for PMD color system calculations
